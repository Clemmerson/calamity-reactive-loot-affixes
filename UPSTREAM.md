# Upstream and permission scope

## Upstream project

- Author: **Eutkyu**
- Mod: [Calamity 2 — Reactive Loot and Affixes](https://www.nexusmods.com/skyrimspecialedition/mods/193193)
- Source repository: [servaltullius/calamity-reactive-loot-affixes](https://github.com/servaltullius/calamity-reactive-loot-affixes)
- FEASR source baseline: upstream commit `989f215e81f3595dc4526a1311437946646a998a`, corresponding to Calamity 2.2.8.

The fork keeps the upstream commit as an ancestor. It does not rewrite upstream history or merge later upstream commits into the FEASR PC1.2 baseline. At preparation time, upstream `main` was at `f08957392f0f5aea2d551f2194a6fffefdaa4dbb`; that newer head is recorded for reference only.

## Permission and required credit

The project owner confirms that Eutkyu authorized publication of the Runeforge expansion, including modified Calamity source code and DLLs. The author requested:

- Credit to Eutkyu.
- A link to the original Calamity 2 Nexus page.
- Clear identification of the modified plugin as the FEASR version, with technical support for FEASR changes directed to FEASR.

This page records the permission scope without reproducing private correspondence. The evidence reference and exact scope are retained in the private project permissions ledger.
