# Support policy

## FEASR-specific issues

Use this repository's GitHub Issues for problems caused by the Runeforge integration or the **FEASR version of `CalamityAffixes.dll`**. Include:

- The exact FEASR branch/build identifier and DLL SHA-256, if available.
- Skyrim runtime, SKSE, Address Library, Calamity, and Prisma UI versions.
- A concise reproduction and the relevant redacted log excerpt.

Do not attach saves, personal files, private messages, credentials, or unredacted machine paths. Report crashes or behavior from a FEASR-modified DLL to FEASR so they are not routed to Eutkyu as upstream issues.

## Upstream Calamity issues

For behavior reproduced with the unmodified upstream Calamity build, use the support route on [Eutkyu's Nexus page](https://www.nexusmods.com/skyrimspecialedition/mods/193193). This fork is not an official upstream support channel.
